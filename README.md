# نظام بطولات حصارات — tournaments-manager

تطبيق ويب بملف واحد (`index.html`) لإدارة بطولات نادي حصارات الرياضي الثقافي الاجتماعي:
كرة القدم ⚽، كرة الطائرة 🏐، الورق 🃏، والطاولة 🎲 — تسجيل، قرعة، مباريات، ترتيب، وأدوار إقصائية.

- **الرابط:** https://hsarat-kids.netlify.app
- **المصدر:** https://github.com/dhoyek/tournaments-manager
- **النشر:** كل `git push` إلى `main` يُنشر تلقائياً على Netlify خلال دقيقة تقريباً.
- **البيانات:** تُحفظ داخل متصفح كل جهاز (localStorage) — لا قاعدة بيانات. لذلك **لا تغيّروا رابط الموقع**: رابط جديد = بيانات فارغة على الهواتف.

## تحديث نسخة
1. عدّل `index.html` وارفع `APPV` (مثلاً `'97'` → `'98'`).
2. ارفع اسم الكاش في `sw.js` بنفس الرقم (`hsarat-kids-v98`).
3. `git add -A && git commit -m "v98: …" && git push`
4. على الهاتف: الإعدادات ← **⬇ جلب أحدث نسخة** وتأكد أنها تُظهر الرقم الجديد.

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | التطبيق كله (HTML + CSS + JS، بلا مكتبات) |
| `sw.js` | Service worker — الشبكة أولاً، والنسخة المحفوظة عند انقطاع الإنترنت |
| `_headers` | منع الكاش على `index.html` و`sw.js` حتى يظهر كل نشر فوراً |
| `manifest.json`، `icon-*.png` | التثبيت على الشاشة الرئيسية |
| `netlify.toml` | إعداد النشر (بلا build، المجلد الحالي) |
